# GameForge AI 高保真原型

GameForge AI 是一个面向游戏创作者的 AI 原生产品高保真网页原型，展示从创意输入、AI 生成到项目管理与协作的核心流程。

## 在线预览

将仓库发布为 GitHub Pages 后，直接打开仓库的 Pages 地址即可体验。项目入口文件为 `index.html`。

## 本地运行

这是一个无构建依赖的静态 HTML 原型。可直接双击 `index.html`，或在当前目录运行：

```bash
python -m http.server 8000
```

然后访问 `http://localhost:8000`。

## 技术说明

- HTML5 / CSS3 / JavaScript
- 响应式布局与交互式高保真界面
- 页面使用 Google Fonts；离线打开时字体会回退到系统字体

> 本仓库用于产品原型展示，不包含真实账号、密钥或后端服务。
